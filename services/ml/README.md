# Laboratorio ML

Implementar aquí experimentos reproducibles con pandas, NumPy y scikit-learn. Cada experimento debe guardar dataset/versionado, variables, target, semilla, versión de librerías, partición temporal, métricas y limitaciones. No usar el módulo para afirmar predicción exacta de futuros terremotos.

Ejemplo de preguntas admisibles: clasificación de eventos ya observados por rango de magnitud; análisis descriptivo de tasas históricas. No se incluye entrenamiento ficticio ni métricas inventadas.
