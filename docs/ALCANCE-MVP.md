# Alcance MVP vs. plan completo

Implementado como base funcional: estructura modular de navegación, dashboard, catálogo de eventos persistidos, mapa con filtros regionales y temporales, análisis descriptivo inicial, diagnóstico de calidad, exportación CSV, conector USGS manual, deduplicación, ejecuciones de ingesta y auditoría básica.

Parcial / pendiente: identidad y roles reales; CRUD administrativo completo; reglas y centro de alertas con entregas y aprobaciones; modelos ML entrenables y registro de artefactos; datasets versionados; reportes PDF/XLSX; trabajos asíncronos, Redis, ingesta programada, PostGIS, migraciones Alembic, backups automatizados, CI/CD y seguridad de producción.

Esta distinción evita presentar pantallas de planificación como funciones operativas ya terminadas.
